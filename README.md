# DLX HTML CSS Starter

A lightweight starter template for vanilla HTML, CSS and JavaScript projects.

## Structure

```text
.cursor/
└── rules/
    └── dlx-frontend.mdc

assets/
├── fonts/
└── images/

css/
├── reset.css
├── tokens.css
├── global.css
├── utilities.css
└── style.css

js/
└── main.js

index.html
.gitignore
README.md
```

## CSS Architecture

- `reset.css` — browser normalization and sensible defaults
- `tokens.css` — design tokens and reusable CSS custom properties
- `global.css` — global element styles
- `utilities.css` — reusable utility classes
- `style.css` — CSS entry point and project-specific styles

## Cursor Rules

The project includes development guidelines for Cursor in:

```text
.cursor/rules/dlx-frontend.mdc
```

These rules define the project's coding conventions, including semantic HTML, BEM naming, design tokens, accessibility, CSS architecture and development workflow.

## Usage

1. Create a new project from this template.
2. Update the design tokens in `tokens.css`.
3. Add project assets to `assets/`.
4. Write project-specific styles in `style.css`.
5. Build.

## Principles

- Semantic HTML
- BEM naming
- Design tokens
- Responsive layouts
- Accessibility
- Minimal dependencies
- Simple, maintainable code
